# Entity Watchdog Autodiscover

Fork der Integration von deepblue120, ergänzt um eine Autodiscover-Funktion. Eine Home Assistant Integration zur Überwachung von Geräten mithilfe von Zeitstempeln der letzten Meldung/Änderung einer Entität.

## Installation über HACS

1. HACS öffnen → Integrationen → Menü (⋮) → Benutzerdefinierte Repositories
2. URL eintragen: `https://github.com/chris-the-swiss/entity-watchdog-autodiscover`
3. Kategorie: Integration
4. "Entity Watchdog Autodiscover" suchen und installieren
5. Home Assistant neu starten

## Manuelle Installation

Ordner `custom_components/entity_watchdog-autodiscover` in dein `config/custom_components/`-Verzeichnis kopieren und Home Assistant neu starten.

## Konfiguration

Über die HA-Oberfläche: Einstellungen → Geräte & Dienste → Integration hinzufügen → "Entity Watchdog Autodiscover" suchen.
